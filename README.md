# 720yun Panorama Downloader

Windows 10/11 x64. Download the ZIP from [Latest Release](https://github.com/StirveHarder/720yun-panorama-releases/releases/latest), extract the whole archive and run the main executable.

Version 1.0.2 and later check this public repository for updates without a GitHub token. Source code is maintained in a separate private repository.

Only download panoramas you are authorized to save. Third-party licenses are included in each package.
